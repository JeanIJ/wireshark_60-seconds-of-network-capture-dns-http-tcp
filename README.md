# Wireshark DNS / HTTP / TCP Lab

Short DNS, HTTP, and TCP captures from a brief network lab, saved as Wireshark `.pcapng` files, plus reflection notes.

Open `dns_capture.pcapng`, `http_capture.pcapng`, and `tcp_capture.pcapng` in Wireshark. The write-up is `Wireshark_Network_Traffic_Reflection.pdf`.
